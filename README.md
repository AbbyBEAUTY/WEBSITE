# Abi Beauty website

Portable static HTML/CSS/JavaScript for Abi Beauty. No framework build step or vendor-specific server code is required.

## Canonical services

- Repository: `AbbyBEAUTY/WEBSITE`
- Production: `https://abi-beauty-honduras.vercel.app`
- Vercel project: `abi-beauty-honduras`
- Supabase backup project: `abi-beauty` (`xxtphnxrnaonmhchkizr`)

GitHub is the source of truth. Use preview-first deployment and promote only the exact verified commit after checking all HTML pages, internal navigation, desktop/mobile layouts, images, missing resources, and console output.

## SEO and affiliate data

The production origin above is authoritative until an approved custom domain replaces it. If it changes, update canonicals, social URLs, JSON-LD identifiers, sitemap, robots, and redirects together.

Public affiliate destinations are centralized in `data/affiliate-links.js`. `data/affiliate-links.example.json` documents the richer intake schema; `affiliate-links-intake.csv` tracks pending destinations. Credentials and private keys never belong in browser code.

`SEO-ARCHITECTURE.md` defines the overall brand/product/category/guide/tool system. `SEO-RESOURCE-PAGES.md` and `data/seo-page-inventory.csv` define the first evergreen shipping-to-Honduras cluster. Provider identity remains blocked until `Shipito` versus `ShipItTo` is verified.

`ASSET-CONTENT-MAP.md` assigns the generated image library to future reviews, comparisons, routines, logistics resources, educational tools, and category pages without treating decorative imagery as firsthand product evidence.

`ASSET-REQUEST-WORKFLOW.md` and `data/asset-requests.csv` define how Codex prepares page-specific prompts for assets Abi creates after SERP-backed page selection.

`ENDLESS-CUSTOMERS-GUIDE.md` adapts Marcus Sheridan's trust, buyer-question, self-service, and assignment-selling framework to Abi Beauty while preserving the Phase 1 → architecture → SERP research → content graph sequence.

The first educational-tool prototype is preserved outside the production branch at `C:\Abby Beauty\_future\beauty-import-readiness`. It identifies missing purchase/shipping information and assigns next tasks without claiming legal, customs, or carrier decisions. Do not publish it before Honduras SERP research validates its role.
